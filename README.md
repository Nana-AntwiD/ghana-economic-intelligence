# Ghana Economic Intelligence

> Building accessible data infrastructure for understanding Ghana's economy.

## Overview

Ghana Economic Intelligence is an open platform for collecting, structuring and analyzing key macroeconomic and financial indicators. 

The project aims to make economic data easier to access, understand, and eventually analyze using statistical and machine learning techniques. 

## V1 Indicators

- Inflation
- USD/GHS Exchange Rate
- Bank of Ghana Policy Rate
- Treasury Bill Rates
- GDP Growth
